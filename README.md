## 🚀 Projects

### [Staż — Clothing Product Description Generator](https://github.com/JakubSzuber/staz)

An internship project that automates the generation of clothing product descriptions using product images and tags. It combines a Django interface with a FastAPI service, AWS Rekognition for image analysis, OpenAI API for description generation, and PostgreSQL for storing product records.

**Technologies:** Python, Django, FastAPI, PostgreSQL, Docker, AWS Rekognition, OpenAI API

### [Fears of the West](https://dzarooo.itch.io/fearsofthewest)

A turn-based card game set in a Wild West atmosphere, developed with Unity. Players use tactical movement, attacks, and unique card abilities to eliminate their opponent's cards. Its distinctive fear mechanic allows damaged cards to transform into stronger mutated forms, adding another layer of strategy to each match.

**Technologies:** Unity, C#
